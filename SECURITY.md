# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private reporting: go to the **Security** tab of this repository and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and the impact. You can expect an acknowledgement within 7 days. We will keep you updated on the fix and credit you if you wish.

## Supported versions

There are no releases yet. Once there are, only the latest release receives security fixes.

## Scope and practices

- Security baseline: [OWASP ASVS](https://owasp.org/www-project-application-security-verification-standard/).
- Secrets scanning runs in pre-commit and CI. Dependencies are monitored by Dependabot.
