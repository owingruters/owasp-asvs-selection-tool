# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Its full text applies to everyone participating in this project's spaces (issues, pull requests, discussions).

In short: be respectful, welcome newcomers, accept constructive feedback, and focus on what is best for the community. Harassment, discrimination and personal attacks are not tolerated.

## Reporting

Report unacceptable behaviour privately to the maintainer via the contact on the maintainer's GitHub profile ([@owingruters](https://github.com/owingruters)). All reports are reviewed and handled confidentially.

## Enforcement

Maintainers follow the [Enforcement Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) of the Contributor Covenant: correction, warning, temporary ban, or permanent ban, depending on severity.
