# ASVS Selection Tool

A tool to help select and scope requirements from the [OWASP Application Security Verification Standard (ASVS)](https://owasp.org/www-project-application-security-verification-standard/).

> **Status:** early foundation. No application code yet.

## Getting started

_Install and run instructions will be added once the stack is chosen._

To work on the repository today:

```sh
pipx install pre-commit   # or: brew install pre-commit
pre-commit install --install-hooks
pre-commit run --all-files
```
